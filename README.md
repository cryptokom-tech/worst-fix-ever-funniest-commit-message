# Worst Fix Ever: Funniest Commit Message

One commit message for a bug fix that made everything worse — an entry for the
[make.fun bounty](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

`main.py` (Python 3.13, stdlib only) writes the entry to `/output/entry.txt`:

> fix: the login page no longer crashes — it now logs everyone in as admin

The login crash is fixed. The price: every visitor is now an admin.
